Lector RSS de terminal con traducción automática de noticias al español.

Usa un poco de scraping para poder procesar artículos y prepararlos para poder ser leidos.
Guarda toda la metralla en una base de datos sqlite3.
Traduce usando la generosidad de nuestro inseparable espía favorito, Gxxxxe.
Implementa filtros estáticos para sitios concretos, no es un lector rss universal per se, los filtros son bastante rústicos.

Hay otros lectores RSS de terminal, pero no encontre uno con traducción automática.

GPL V3
